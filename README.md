# ☀️ AuraWeather 3D • Real-time Motion Forecast

An ultra-modern, Apple and Linear-grade Weather Web Application featuring real-time meteorological data, interactive 3D weather visualizers (Three.js), spring physics animations (Framer Motion), interactive magic particle click effects ("हर क्लिक में मैजिक"), and a 100% free real-time API (Open-Meteo).

## 🌟 Key Highlights

- **100% Free Open-Meteo Meteorological API:** No API keys or credit cards required. Real-time temperature, wind compass, UV index, atmospheric pressure, humidity, visibility, and Air Quality (AQI).
- **Procedural 3D Weather Models (Three.js):**
  - ☀️ **Sunny:** 3D glowing solar sphere with animated corona flares.
  - ⛈️ **Thunderstorm:** Volumetric storm clouds with real-time procedural lightning flashes.
  - 🌧️ **Rain:** 1,400+ 3D rain particles with wind angles.
  - ❄️ **Snow:** 800+ 3D tumbling crystalline snowflakes.
  - 🌙 **Starry Night:** 1,200+ celestial twinkling stars & glowing moon.
- **"हर क्लिक में मैजिक" (Interactive Magic FX):**
  - Every click or tap anywhere on the screen triggers glowing diamond sparks, starbursts, and shockwave energy rings.
- **100% Auto-Fit & Auto-Screen Standard:**
  - Zero horizontal scroll (`overflow-x: clip`).
  - Fluid `clamp()` typography and self-wrapping dynamic grids.
  - 3D tilt spotlight cards with cursor glow & magnetic CTA buttons.
- **Global Search & GPS Auto-Detect:**
  - Debounced autocomplete for any city worldwide + 1-click GPS location detection.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Mohit12836/aura-weather-3d.git

# Navigate to project directory
cd aura-weather-3d

# Install dependencies
npm install

# Start local dev server
npm run dev
```

## 🛠️ Tech Stack

- **Framework:** React 18 with Vite & TypeScript
- **3D Graphics:** Three.js (WebGL)
- **Animation:** Framer Motion (Spring Physics & Odometers)
- **Styling:** Tailwind CSS with Glassmorphism
- **Icons:** Lucide React
- **Meteorology:** Open-Meteo Free API
